## Abschluss

- `npx tsc --noEmit -p .` in `apps/portal`: bricht mit Syntaxfehlern in `src/worker/processors/pvs-csv-ingest.test.ts` (Zeile 166-168, "Unterminated string literal") ab; die Datei gehört der anderen Sitzung (Nie-anfassen-Liste). Dadurch meldet tsc keine semantischen Fehler. Ersatzlauf mit einer Kopie der tsconfig ohne diese Datei (im Scratchpad, nicht im Repo): 0 Fehler unter `src/app/admin`, `src/server/guarantee*`, `src/server/response*`, `src/server/queries/admin*`. Übrige Meldungen im Ersatzlauf liegen in fremden Dateien (`Buffer`/`ArrayBuffer`-Typen in `server/pvs-event-integrity.ts`, `server/storage.ts`, `worker/processors/*`, `lib/crypto.ts`, `db/seed.ts`, `scripts/setup-intake.ts`), vermutlich durch die andere Auflösung der Node-Typen beim Lauf aus dem Scratchpad; nicht von DS5.
- `npx vitest run src/auth/admin-gate.test.ts src/app/admin`: 3 Dateien, 15 Tests grün. Keine weiteren Tests importieren die geänderten Module.
- Alle Admin-Seiten rufen weiter ihren Guard; keine neue Abfrage, keine Server-Aktion geändert.
- Kein Gedankenstrich (U+2014) unter `app/admin`, kein `uppercase`/`tracking-wid` mehr.

## Braucht andere Datei

- `src/worker/processors/pvs-csv-ingest.test.ts` (andere Sitzung): Syntaxfehler Zeile 166-168 blockiert `tsc` für das ganze Portal.
- `admin/pvs-bridge/konfigurationen/page.tsx`: Knopf "Zurückziehen" (`revokeConfigAction`) ist ein `ghost`-Knopf ohne Rückfrage und ohne Wartezustand. Laut Auftrag in pvs-bridge nur Versal entfernt; Umstellung auf `DangerSubmitButton` braucht Freigabe.
- `admin/videos/[id]/page.tsx` Tabelle `min-w-[640px]` (Ereignisse eines Videos) scrollt am Handy weiter seitlich; nicht im Auftrag (nur Garantie, Rückruf, Videos-Liste).

## Nicht getestet

- Keine Sichtprüfung im Browser (Auftrag). Startseite, Handy-Spalten, "Wie wird gerechnet?" und die roten Knöpfe sind nur per Typecheck geprüft.
